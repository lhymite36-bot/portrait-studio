# Portrait Studio 1.2.1 (versionCode 5)

Bug-fix release. Same signing key as 1.0–1.2.0, so it installs over the old version and keeps your settings.

## Fixed: "NotReadableError" when saving/exporting
**Root cause:** On Android, a file picked through the system picker is handed to the app's WebView as a
temporary `content://` permission. The app kept only a reference to that file and read it again later
(video demuxing, audio track, preview `<video>`, Studio export). If the export ran minutes later, or
after the picker or gallery app released the permission, the read failed with `NotReadableError`.

**Fix:** every picked file (photo, video, audio, background/sky images, Studio media, batch) is copied
into the app's private storage (OPFS; memory if that's unavailable) right when it's picked, with
progress, three retries and a clear "please pick it again" message if the copy fails. After that the
app never touches the original again. Old copies are cleaned up on start and when replaced.
Test: `tests/headless/revoked.py` lets each picked file be read only once and makes later reads fail.

## Fixed: Studio play preview went blank
**Root cause:** the preview cleared the canvas to black and then waited for the frame to decode; with
the `<video>` path each frame also needed a seek on a paused element, which Android WebView often
doesn't paint. So most of the time during playback you saw the black, half-drawn canvas.

**Fix:** frames now come from a WebCodecs decoder reading the private copy (keyframe seek + sequential
decode), with `<video>` as fallback. During playback the fallback `<video>` plays in step with the
timeline instead of seeking every frame. Rendering is double-buffered, so the screen only ever shows
finished frames, and a poster frame is drawn when you pause.

## Fixed: couldn't delete clips on a touchscreen
- Tap a clip to select it: a bar appears above the timeline with **🗑 Delete**, Split, Copy, move ◀ ▶, ✓.
- Long-press any clip/overlay/text/audio for a Delete / Split / Duplicate menu.
- Toolbar now starts with a 🗑 button (dimmed when nothing is selected).
- Dragging a selected clip/its edges moves/trims without the timeline rebuilding under your finger.
Test: `tests/headless/studio_touch.py` (touch-emulated phone viewport: tap, long-press, toolbar trash,
play preview pixel sampling in both the WebCodecs and `<video>` paths).

Tested in headless Chrome with phone-sized touch emulation, not on a physical phone.
