# Portrait Studio v1.1.1 (portrait detection fix)

Install **PortraitStudio-1.1.1.apk** below. It updates v1.1.0 in place and keeps your settings.

## Fixed
- **"Portrait detection unavailable: Aborted()"** on some phones (for example the Galaxy A05), which meant the blur never applied.
  - **Cause:** the phone's camera photos (up to 50 MP) were sent to the person detector at full size. On phones where the GPU path is not used, the detector then tried to allocate several full-size masks in WebAssembly memory. It ran out of memory and aborted.
  - **Fix:** photos are now resized for detection (up to 1536 px), and the mask is scaled back up. The edge-aware refine still works at full resolution, so the edges stay sharp.
- **Automatic fallbacks:** if a detection engine fails to load or crashes, the app moves on to the next one, and no internet is needed for any of them. The order is:
  1. multiclass model on the CPU
  2. the same model on the GPU
  3. the non-SIMD build
  4. the smaller selfie model
  5. a separate ONNX Runtime engine with the U²-Net-p model (all bundled)
- If every engine fails, the message now says what each one reported, so the problem can be fixed.

## Tested
- Headless Chrome set up like a budget WebView: no SharedArrayBuffer, not cross-origin isolated, WebAssembly memory capped at 512 MB, and a 50 MP photo. v1.1.0 reproduces the exact "Aborted()" error, and v1.1.1 detects the person.
- Each fallback engine was also forced on its own and works, including recovery after a crash during detection.
- Not yet tested on a real phone.
